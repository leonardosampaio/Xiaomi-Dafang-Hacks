Cloudflare Tunnel





























Create a tunnel in the Cloudflare Zero Trust dashboard (Networks > Tunnels), paste its token below and add public hostnames pointing to the camera services (e.g. https://localhost:443 with "No TLS Verify", or ssh://localhost:22). Start the service in Control System > Services.








Web UI access through the tunnel

Requests that come through the tunnel must log in with this user and password (local network access is not affected). Without a user, every request through the tunnel is denied. Leave the password empty to keep the current one.



Failed login ban

IPs that fail the login through the tunnel this many times within the ban duration are blocked (HTTP 403) for that duration. Use 0 to disable.
